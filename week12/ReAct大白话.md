ReAct 可以理解成一个会分工合作的流程，不是一个人从头做到尾。第一步先判断还缺什么信息、下一步该怎么做；第二步负责出去查资料、做测试或获取需要的信息；第三步把结果带回来，检查这些信息够不够回答问题。如果还不够，就根据新结果再继续查、继续验证，直到信息足够，最后再给出答案。所以它更像是“有人负责想，有人负责跑，有人负责反馈”，三步不断循环配合完成任务。
CoT 则不同，它会一直沿着自己的思路推理，如果一开始理解错了，后面的推理也可能一直错下去，因为它不会主动去获取新的信息来验证自己的想法。ReAct 则可以在过程中不断获取真实结果，再根据结果修改后面的思路，就像做题时发现线索不对，马上换一种方法继续，而不是一直按原来的方向推下去。简单来说，CoT 是“一直想”，ReAct 是“边想边做、边做边改”。
