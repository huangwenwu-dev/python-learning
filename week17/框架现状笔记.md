# 第17周 D5 · 框架现状笔记

## 1. 三家关系
AutoGen 是微软的老框架，现在只修不更新；Microsoft Agent Framework 是 AutoGen 的接班框架，新功能都放这里；AG2 是社区拿 AutoGen 老写法分出去单干的。

> ⚠ 坑：网上的 `autogen` 安装包，装下来可能是 AG2，不是微软那个。

## 2. AG2 解决什么问题
让多个 Agent 像拉群开会一样，你一句我一句地来回对话、互相改。

## 3. Microsoft Agent Framework 解决什么问题
微软原来有 AutoGen 和 Semantic Kernel 两套工具，各管各的，开发者不知道该用哪个。现在合成一套，正式版、长期维护，给企业做正经上线的 Agent 用。

## 4. 对话式 vs 工单式
| | 适合 | 网店例子 |
|---|---|---|
| 对话式（AG2 开会） | 需要灵活讨论的事 | 售后纠纷：客服、运营、仓库一起商量怎么处理 |
| 工单式（CrewAI 交单） | 固定流水线的活 | 上新：拍图 → 修图 → 写详情 → 上架 |

## 5. 看到新框架，先查三件事
1. 还更新吗？
2. 我装的是哪家、哪版？
3. 教程是哪年的？
