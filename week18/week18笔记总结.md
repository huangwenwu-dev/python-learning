## 四、闭卷读码（D7）

代码：`fetch_price`，`DELAYS = [1, 3]`，只重试 `ConnectionError`、`TimeoutError`。

| 题 | 我的答案 | 对错 |
|---|---|---|
| 认零件：`range(len(DELAYS)+1)` 让 i 是几 | 先答 1,3 / 2,4，选 A（1,2,3） | ❌ 实为 0,1,2 |
| 认零件：成功后循环还走吗 | 不会 | ✅ |
| 1 最多重试几次 / 打几次电话 | 2 / 3，凭 `DELAYS` 和 `range(...)` | ✅ |
| 2 全失败一共等几秒 | 卡住，拆开后答 4 | ⚠ |
| 3 抛错还是返回一句话 | 返回"查询失败,请稍后再试" | ✅ |
| 加分1 第2次成功 | 2 次电话，打印 1 行 | ✅ |
| 加分2 抛 ValueError | 不重试不等，凭 `except RETRY_ON` 接不住，往外扔 | ✅ |

**更正句**：我当时不认识 `len`、`range`、`DELAYS[i]`，只能乱猜。实际是：`len` 数有几样；`range(3)` 从 0 开始数，不包括 3；`DELAYS[i]` 从第 i 号格子拿数，编号从 0 开始。

**结论**：本周新知识（打几次电话、等几秒、名单管接什么）闭卷全对；卡的是**第1周的老零件**。
