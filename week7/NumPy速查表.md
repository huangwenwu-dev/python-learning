# NumPy 速查表

## 一、创建数组
np.array([...])                # 从列表转（一维/二维）
np.arange(起, 止, 步长)         # 等差（不含末尾）
np.zeros(形状) / np.ones(形状)  # 全0 / 全1，形状用元组
np.linspace(起, 止, 个数)       # 均匀取N个（含末尾）

## 二、查看数组（属性，不加括号）
.shape    # 形状（几行几列），最重要
.ndim     # 几维
.dtype    # 元素类型
.size     # 总元素数

## 三、索引与切片
arr[行, 列]         # 二维取值（一个方括号、逗号分隔）
arr[行, :]          # 取一整行
arr[:, 列]          # 取一整列
arr[arr > 值]       # 布尔索引（条件筛选）
# 组合条件：(条件1) & (条件2)，用 & | 不用 and/or

## 四、形状变换
arr.reshape(行, 列)   # 变形（总数须相等）
arr.reshape(-1, n)    # -1 自动推断某一维
arr.flatten()         # 拉平成一维
arr.T                 # 转置（行列互换）

## 五、运算
arr + 10 / arr * 2   # 数组与标量（每个元素都算）
a + b / a * b        # 逐元素（对应位置，≠ 矩阵乘）
a @ b                # 矩阵乘法（行乘列求和，位置会变）
# 广播：小的自动扩展、对齐到大的，再逐元素算
# 矩阵乘形状：(m,n)@(n,k)=(m,k)，中间配对消掉留两头
#   例：(2,3)@(3,4) → (2,4)

## 六、我要记牢的三个区别（自己的话写清楚）
- 数组*2 vs 列表*2
  → 数组：每个元素乘2；列表：整个重复一遍、变两倍长
- @（矩阵乘）vs *（逐元素）
  → @：行乘列求和、shape会变；*：对应位置相乘、shape不变
- reshape 的总数铁律
  → 变形前后总元素数必须相等，-1 让某一维自动算

## 七、承前启后（神经元 → 大模型）
神经元：输出 = 输入 @ 权重 + 偏置   # 加权求和用@，加偏置用广播
神经元和大模型的关系 → 结构:大模型 = 海量神经元堆叠, 运算:底层 = 海量矩阵运算
