# 上下文工程完整心智模型

## 一、核心认知(一句话)
上下文工程 = 在有限的上下文**预算**里，决定每一轮放什么、不放什么——放进去的每一条，都挤掉了另一条。

## 二、为什么它取代了"提示工程"
- 提示工程关心：怎么写这句**指令**（第 10 周整周：四要素、Few-shot、CoT、system、temperature）
- 上下文工程关心：给模型**看什么信息**（第 13 周整周：记忆、检索、过滤、压缩、注入）
- 为什么后者更根本：指令是"怎么答"，上下文是"拿什么答"。提示词再好，关键信息不在上下文里模型就是不知道。提示工程没消失，它变成了其中一环——包含，不是取代

## 三、问题：长对话的三大病
| 病 | 症状 | 根源 |
|---|---|---|
| 失忆 | 第二轮起答不了含"它""那…呢"的指代问题，反问或编造；补全成完整句子又答得对 | 模型无状态，只看得见这次请求塞进去的内容；历史只增不减，撞窗口上限被截断 |
| 跑偏 | 中后期回答变笼统，或编造没说过的细节且语气笃定（加戏）；换干净会话重问反而更准 | 有用信息**占比**被稀释——这是**比例**问题，与上下两病的**量**问题不同 |
| 烧钱 | 第 1 轮 8 token → 第 20 轮 8352，增速越来越快 | 每轮把全部历史**重新提交**，成本随"一共说了多少"走，曲线是二次的。与失忆**同源**；窗口有限只是第二道墙，第一道墙是钱包 |

## 四、手段清单(⭐ 面试会问"有哪些手段")
| 手段 | 解决什么 | 我怎么实现的 | 代价/风险 |
|------|----------|--------------|----------|
| 短期记忆(checkpointer) | **会话内**失忆 | `InMemorySaver()` 传给 `create_agent`；`config={"configurable":{"thread_id":...}}` 隔离会话；指代测试验收 | 一关即失（可换 `SqliteSaver`，本周未做）；**治失忆的同时制造烧钱**，8→8352 就是它造的 |
| 长期记忆(store/文件) | **跨会话**失忆（偏好、稳定事实） | 手写四函数存 `memories.json`，`user_id` 作隔离键，`build_system_prompt` 拼进 system；只在用户明说时才存 | 每轮都拼→**加重烧钱**；无校验无过期，存错一条污染该用户**全部**后续会话；"明说才存"的代价是漏记 |
| 摘要压缩 | 烧钱 + 截断式失忆 | `SummarizationMiddleware`：`trigger=("tokens",2000)`、`keep=("messages",4)`、小模型 `deepseek-chat`；`get_state` 看到是**删旧换摘要**，替换不是折叠 | 风险是摘掉后面要用的细节且**不报错**；但本次对照测试**未丢信息**，真实副作用是前缀一变**cache_read 归零** |
| 检索(RAG) | 跑偏 + 外部知识不在窗口里 | Chroma 持久化库 + `as_retriever(search_kwargs={"k":3}).invoke()`；封装成 `search(query, source=None, k=3)` | **万能块**：10 题里 8 题捞到同一块，白占坑位；**Top-K 是硬指令**，不相关也凑够三条；块太大稀释、太小断上下文 |
| 元数据过滤 | 跑偏（先缩范围再搜，同 SQL `WHERE`） | 写入定死 `source`/`chunk_index`；查询"先建后传"拼 `filter` | **不存在的 source** 与**键值类型写错**（`0` vs `"0"`）都静默返回空，表现一样、无法反推病因 → 键值写入时定死；主题差太远时 filter 加不加一个样 |
| 注入策略(K值/位置) | 跑偏（塞多少 / 塞在哪） | Top-K=3；最相关的靠近问题、**避开正中间**（lost in the middle） | K 小漏信息、K 大灌噪声，无固定最优值；位置这条**本周未做对照实验**，待第 14 周验证 |

## 五、一张决策图(自己画)
什么信息 → 该放哪？（尺子：先造使用场景，再两问——换新窗口还用得上吗？会不会过期？）
- 这轮对话的细节 → **短期记忆(checkpointer)**
- 用户的稳定偏好 → **长期记忆(文件/Store)**
- 大量文档知识 → **检索(RAG)**
- 会过期的信息 → **短期记忆，或干脆不记**（记了就是定时炸弹：不报错，只在某天悄悄给个过时答案）

## 六、我踩的坑
- **静默失败四连**（都不报错、结果是错的）：filter 不存在的 source ／ 键值类型 `0` vs `"0"` ／ 取错抽屉（`response_metadata` 里找 `usage`，实为 `token_usage`）／ 误删整段 `for` 循环只剩 `def`。对策：先 `print` 真实结构，"没报错"不等于"跑对了"
- **两条反方向的路径规则**：`./` 从运行目录算，`import` 从脚本目录算 → `python -m week13.migrate_chroma`
- **`rag.py` 末行 `main()` 顶格**，一被 import 就跑起来卡在 `input()` → `if __name__ == "__main__"`（Day 4 又撞一次）
- 文件名以数字开头不能当模块名；路径一律用 `/`
- **命名撞车**：`client` 被 Chroma 覆盖导致 `embed_text` 失效；自定义函数取名 `create_agent` 撞框架
- **版本坑**：`ToolStrategy` + `deepseek-v4-pro` 报 400（思考模式不支持 `tool_choice`）；中间件参数名新旧两套 → 只信官方文档 + `inspect.signature`
- **缩进**：`return` 被关进 `else`；`middleware=[...]` 掉出 `create_agent` 括号外
